# 🧭 청년 지원 내비

**교육·지원금 조합과 신청 순서를 설계하는 AI 에이전트**
2026 대한민국 청년 CAREER FAIR AI 해커톤 출품작

취업을 준비하는 청년이 자기 상황을 말로 적으면, 국비 교육(KDT, K-뉴딜 아카데미, 내일배움카드)을 들으면서
**같이 받을 수 있는 지원금 조합**과 **무엇부터 신청해야 손해가 없는지(순서)**를 공식 근거와 함께 알려줍니다.

## 왜 필요한가
온통청년·보조금24·청년몽땅정보통은 "받을 수 있는 정책"을 찾아주고 정책 하나씩 자격을 판정해 줍니다.
하지만 "A를 받으면 B를 못 받는지", "무엇부터 신청해야 하는지"는 청년이 공고를 직접 읽고 판단해야 합니다.
예: 서울시 청년수당을 먼저 받으면 끝난 뒤 6개월 동안 국민취업지원제도 Ⅰ유형에 참여할 수 없습니다.

## 구조

```
상황 문장 ──▶ ① AI(Gemini): 입력 정리 (개인정보는 보내기 전에 가림)
          ──▶ ② 확인·되묻기 화면: 사용자가 고치고 빈 곳을 채움
          ──▶ ③ 규칙 엔진(engine.py): 자격 판정 + 조합·순서 계산  ← 판정은 여기서만
          ──▶ ④ AI(Gemini): 결과를 쉬운 말로 설명 (엔진이 준 사실만 사용)
          ──▶ ⑤ 화면: 추천 경로, 신청 순서, 제도별 판정, 근거(공식 출처 링크)
```

- **판정은 규칙이, 이해와 설명은 AI가 합니다.** AI가 자격을 추측하지 않게 해서 틀린 답을 지어내는 문제를 막습니다.
- 규칙이 불분명한 조합(예: K-뉴딜 아카데미와 다른 수당)은 판정하지 않고 **"확인 필요"와 문의처**를 보여줍니다.
- AI 키가 없거나 사용량 한도에 걸려도 **직접 입력 모드**로 판정은 계속됩니다.

## 파일

| 파일 | 내용 |
|---|---|
| `app.py` | Streamlit 화면 (입력 → 확인·되묻기 → 결과·근거) |
| `engine.py` | 규칙 엔진: 정책 7개 자격 판정, 조합·순서 계획, 근거 연결 |
| `llm.py` | Gemini 연동: 입력 정리, 결과 설명, 개인정보 가리기 |
| `data/policies.json` | 규칙표 (정책 7개, 정책 간 관계 15개, 2026 기준 중위소득, 출처) |
| `personas.py` | 시연·테스트용 가상 인물 5명 (실제 개인정보 아님) |
| `tests/test_engine.py` | 가상 인물 5명 + 추가 사례 판정 테스트 |

## 다루는 제도 (기준일 2026-11-18)
- 지원금: 실업급여, 국민취업지원제도 Ⅰ·Ⅱ유형, 서울시 청년수당
- 교육: 국민내일배움카드, K-디지털 트레이닝(KDT), K-뉴딜 아카데미

## 실행 방법
```bash
pip install -r requirements.txt
python tests/test_engine.py        # 규칙 엔진 테스트
streamlit run app.py
```
Gemini API 키는 `.streamlit/secrets.toml`에 `GEMINI_API_KEY = "..."` 형식으로 넣습니다 (`secrets.toml.example` 참고).
이 파일은 `.gitignore`에 들어 있어 저장소에 올라가지 않습니다.

## 개인정보와 AI 한계 대응
- 이름·연락처·주민번호를 묻지 않고, 입력창에 입력 금지 안내를 둡니다.
- 전화번호·주민번호·이메일 형태는 AI로 보내기 전에 코드에서 가립니다. 입력 내용은 저장하지 않습니다.
- AI가 쓴 설명에는 "AI가 생성한 설명입니다"를 표시합니다.
- 모든 판정에 규칙 ID(P1~P7, R1~R15)와 공식 출처 링크를 붙입니다.
