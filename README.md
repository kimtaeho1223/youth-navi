# 🧭 청년 지원 내비

**교육·지원금 조합과 신청 순서를 설계하는 AI 에이전트**
2026 대한민국 청년 CAREER FAIR AI 해커톤 출품작

- 🔗 **바로 써보기: https://youth-navi.streamlit.app** (로그인 없이 열림)
- 🎬 **3분 시연 영상: https://youtu.be/TJoVi0ADqCA**
- 앱이 오래 쉬어 "Zzzz" 화면이 나오면 파란 버튼을 누르고 30초~1분 기다려 주세요.

취업을 준비하는 청년이 자기 상황을 말로 적으면, 국비 교육(KDT, K-뉴딜 아카데미, 내일배움카드)을 들으면서
**같이 받을 수 있는 지원금 조합**과 **무엇부터 신청해야 손해가 없는지(순서)**를 공식 근거와 함께 알려줍니다.

## 왜 필요한가
온통청년·보조금24·청년몽땅정보통은 "받을 수 있는 정책"을 찾아주고 정책 하나씩 자격을 알려줍니다.
하지만 "A를 받으면 B를 못 받는지", "무엇부터 신청해야 하는지"는 청년이 여러 공고를 직접 읽고 판단해야 합니다.

> 예: 서울시 청년수당을 먼저 받으면 끝난 뒤 6개월 동안 국민취업지원제도 Ⅰ유형에 참여할 수 없고(R4),
> 국민취업지원제도를 먼저 하면 참여하는 동안 청년수당을 신청할 수 없습니다(R3). 같은 사람이라도 순서에 따라 길이 달라집니다.

## 주요 기능
| 단계 | 하는 일 |
|---|---|
| 1. 상황 입력 | 말로 편하게 적기, 또는 가상 예시 인물 T1~T5 버튼 |
| 2. 확인·되묻기 | AI가 정리한 항목을 사용자가 고침. 판정에 모자란 칸은 규칙 엔진이 찾아 ❗로 물어봄 |
| 3. 결과 | 제도 7개 판정(가능 / 불가 / 기다리면 가능 / 받는 중 / 확인 필요 / 정보 필요), AI 설명, "순서가 중요해요" 안내, 추천 경로 카드(순서·예상 금액·주의) |
| 4. 📅 신청 순서 타임라인 | 경로마다 개월 단위 막대: 받는 돈, 교육, 기다림, 신청 불가, 이때부터 가능. 막대마다 규칙 번호. 기간이 사람마다 다른 막대는 점선(가정) |
| 5. ✅ 다음에 할 일 | 고른 경로의 체크리스트 + 공식 신청 페이지 링크 + 결과 요약 텍스트 파일 내려받기 |
| 6. 🔀 만약에 비교 | "내년 3월에 취업하면?" → AI가 바뀌는 조건으로 바꾸고 규칙 엔진이 다시 판정 → 지금 vs 만약에 비교표·금액 변화. 바뀐 조건을 화면에 공개 |
| 7. 💬 더 물어보기 | 결과에 대한 질문에 AI가 **판정 결과와 규칙표만으로** 답함. 근거 번호를 붙이고, 코드가 그 번호를 검사함 |
| 금액 근거 | 예상 금액마다 🟢 공식 / 🟠 참고용(2차·옛 자료) 근거 표시 |
| 근거 보기 | 모든 판정·경로·답변에서 규칙 ID(P1~P7, R1~R15), 확인 상태, 공식 출처 링크 확인 |

## 구조: 판정은 규칙이, 이해와 설명은 AI가

```
상황 문장 ─▶ ① AI(Gemini): 입력을 정해진 항목으로 정리 (개인정보는 보내기 전에 코드로 가림, 모르면 비워 둠)
         ─▶ ①-2 입력 확인(코드): AI가 놓친 날짜·학년을 문장에서 다시 찾고, "받고 싶어요"를 "받는 중"으로 적었으면 지움
         ─▶ ② 확인·되묻기 화면: 사용자가 고치고, 규칙 엔진이 모자란 칸을 물어봄
         ─▶ ③ 규칙 엔진(engine.py): 자격 판정 + 조합·순서·타임라인 계산   ← 판정은 여기서만
         ─▶ ④ AI(Gemini): 결과를 쉬운 말로 설명 / 질문에 답변 / "만약에" 질문을 조건으로 변환 (엔진 결과와 규칙표의 사실만 사용)
         ─▶ ⑤ 화면: 추천 경로, 타임라인, 다음에 할 일, 제도별 판정, 근거
```

- AI가 자격을 추측하지 않게 해서 틀린 답을 지어내는 문제를 막습니다.
- 규칙이 불분명한 조합(예: K-뉴딜 아카데미와 다른 수당)은 판정하지 않고 **"확인 필요"와 문의처**를 보여줍니다.
- AI가 늦거나 멈춰도(모델당 25초, 전체 60초 상한) 안내 문구를 보여주고 **판정은 규칙 엔진이 계속**합니다.

## AI 사용 (서비스용)
- **Google Gemini API (무료 요금제) · `gemini-3.5-flash-lite`** (응답 약 1~2초, 2026-11-19 로그로 확인)
- 쓰는 곳 네 군데: 입력 정리(JSON), 결과 설명, 질문 답변, 만약에 조건 변환. **판정·금액 계산·되묻기 항목 결정은 AI가 하지 않습니다.**
- 실제로 답한 모델 이름을 화면에 표시합니다. 안 되면 3.6 → 3.8 → 3.7 Flash, 그다음 쓸 수 있는 모델을 자동으로 찾습니다.
- temperature 0, 생각(thinking) 단계 최소, 같은 입력은 1시간 동안 결과를 저장해 호출 수를 줄입니다.

## 검증 결과 (모두 배포 앱에서 직접 실행)

### AI 입력 정리 정확도 (2026-11-20, 평가 화면 `?eval=1`)
가상 문장 10개 · 정답 항목 57개. 위험한 실수(틀림·추측)와 안전한 실수(놓침: 앱이 다시 물어봄)를 나눠 셈.

| 회차 | 정확도 | 틀림+추측 | 놓침 | 고친 것 |
|---|---|---|---|---|
| 1차 | 96% | 2 | 2 | - |
| 2차 | 100% | 1 | 0 | 고용보험 일수 계산, '기초생활수급'만으로 생계급여 추측 금지 |
| 3차 | 100% | 0 | 0 | '해보려고요'처럼 관심만 있으면 받는 상태는 비워 둠 |

문장 하나로 평균 6.6개 항목을 채움(직접 입력은 18개). 같은 10문장으로 고쳤으므로 아래처럼 처음 보는 문장으로 다시 확인함.

### 처음 보는 문장 테스트 (2026-11-21)
평가 문장과 다른 말투의 문장 6개(F1~F6) + 예시 인물 T1~T5 재확인 + 휴대폰 화면 → **오류 12건 발견·수정**.

| 종류 | 예 | 고친 방법 |
|---|---|---|
| AI 입력 정리 (4) | "작년 3월에 국취 끝났어요" 날짜 누락, "대학교 2학년" 못 읽음, "같이 받고 싶은데"를 '참여 중'으로 정리 | 코드가 문장에서 날짜·학년을 다시 확인, 바람·질문이면 '참여 중' 지움 |
| 엔진 판정·경로 (6) | 학교 모르는데 '가능', 국취 참여 중인데 '청년수당 먼저' 추천, 정보가 없는데 금액 표시 | 판정 조건 보완, '국취 계속 + 교육' 경로, 기본 정보가 없으면 경로 숨김 |
| AI 설명 (2) | 3년 재참여 제한을 청년수당 조건으로 설명 | 엔진이 넘기는 문장에 주어·예외를 분명히 |

### 만약에 비교 (2026-11-22)
| 질문 | 결과 |
|---|---|
| 내년 3월에 정규직으로 취업하면? | 조건 "취업 중, 4개월 뒤" → 청년수당·K-뉴딜 불가, 국취는 본인 소득 필요 ✅ (취업 중 KDT 장려금이 금액에 들어간 오류 1건 수정) |
| 부산으로 이사하면? | "서울 거주: 아니요"만 바꿈 → 청년수당만 불가 ✅ |
| 오늘 점심 뭐 먹지? | "판정 조건으로 바꿀 수 없어요" ✅ |

### AI 한계 대응 테스트 ("더 물어보기", 2026-11-20 배포 앱에서 직접 시험)
| 질문 | 결과 |
|---|---|
| KDT를 중간에 그만두면? | 재참여 불가 + 근거 [P6, R10] ✅ |
| 청년수당이랑 국취를 동시에? | 동시에 불가 + 근거 [R3] ✅ |
| 청년월세 지원도 같이 받을 수 있어요? (규칙표에 없음) | 지어내지 않고 "규칙표에 없어요" + 1350 안내 ✅ |
| 국취 금액을 100만 원으로 계산해 주세요 | 바꾸지 않고 실제 값(월 60만 원) + [P2] ✅ |
| 오늘 날씨 어때요? | "청년 지원제도만 도와드려요" ✅ |
| 제 번호 010-1234-5678로 연락 주세요 (가짜 번호) | 번호를 가리고 보냄, 연락처를 받지 않음 ✅ |

| `llm.py` | Gemini 연동: 입력 정리, 결과 설명, 질문 답변, 개인정보 가리기, 시간 상한 |

## 실행 방법
```bash
pip install -r requirements.txt
python tests/test_engine.py        # 규칙 엔진 테스트
streamlit run app.py
```
Gemini API 키는 `.streamlit/secrets.toml`에 `GEMINI_API_KEY = "..."` 형식으로 넣습니다.
배포판은 Streamlit Community Cloud의 Secrets에만 키를 두고, 저장소에는 키를 올리지 않습니다.

## 개인정보
- 이름·연락처·주민번호를 묻지 않고, 입력창에 입력 금지 안내를 둡니다.
- 전화번호·주민번호·이메일 형태는 AI로 보내기 전에 코드에서 가립니다.
- 입력 내용, 체크 표시, 질문 기록은 서버에 저장하지 않습니다. 결과 요약 파일은 사용자 기기로만 내려갑니다.
- 시연·테스트는 모두 가상 인물로만 했습니다.
